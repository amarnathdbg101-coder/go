# Technical Specification: go-ledger

## 1. Domain & Purpose
`go-ledger` is a deterministic, zero-dependency double-entry bookkeeping engine, general ledger, and accounts receivable aging processor for Go. It guarantees mathematical balance invariance ($\sum \text{Debits} = \sum \text{Credits}$) on every financial transaction, provides atomic journal entry posting, and classifies delinquent balances into standard risk aging brackets.

## 2. Architecture & Design Principles
- **Double-Entry Invariance**: Every posting event requires at least two legs. An unbalanced entry ($\sum \text{Debits} \neq \sum \text{Credits}$) is rejected before mutating account states.
- **Subunit Integer Precision**: All currency calculations are executed in integer minor subunits (e.g. Paisa, Cents) to eliminate floating-point rounding errors (`0.1 + 0.2 != 0.3`).
- **Normal Balance Semantics**:
  - `ASSET` / `EXPENSE`: Normal balance is Debit ($\text{Balance} = \text{Debits} - \text{Credits}$).
  - `LIABILITY` / `EQUITY` / `REVENUE`: Normal balance is Credit ($\text{Balance} = \text{Credits} - \text{Debits}$).
- **Reversal and Audit Trail**: Journal entries are immutable once posted. Adjustments and cancellations are executed via contra-entries generated by `CreateReversal`.
- **Delinquency Aging Engine**: Categorizes outstanding balances into standard accounting aging brackets: Current (0-30 days), 31-60 days, 61-90 days, and 90+ days overdue.
- **Zero Third-Party Dependencies**: Pure Go standard library (`math`, `sync`, `time`).

## 3. API Surface
- `type AccountType string (TypeAsset, TypeLiability, TypeEquity, TypeRevenue, TypeExpense)`
- `type Account struct`
- `func NewAccount(id, name string, accType AccountType, currency string) (*Account, error)`
- `func (a *Account) BalanceSubunits() int64`
- `func (a *Account) BalanceFloat() float64`
- `type Direction string (Debit, Credit)`
- `type PostingLine struct`
- `type JournalEntry struct`
- `func NewJournalEntry(id, description, reference string, date time.Time) *JournalEntry`
- `func (j *JournalEntry) AddDebit(accountID string, amountSubunits int64, description string) *JournalEntry`
- `func (j *JournalEntry) AddCredit(accountID string, amountSubunits int64, description string) *JournalEntry`
- `func (j *JournalEntry) AddDebitFloat(accountID string, amountFloat float64, description string) *JournalEntry`
- `func (j *JournalEntry) AddCreditFloat(accountID string, amountFloat float64, description string) *JournalEntry`
- `func (j *JournalEntry) Validate() error`
- `func (j *JournalEntry) CreateReversal(reversalID, reason string) (*JournalEntry, error)`
- `type Ledger struct`
- `func NewLedger() *Ledger`
- `func (l *Ledger) RegisterAccount(acc *Account) error`
- `func (l *Ledger) GetAccount(id string) (*Account, error)`
- `func (l *Ledger) Post(entry *JournalEntry) error`
- `func (l *Ledger) TrialBalance() TrialBalanceReport`
- `func CalculateAging(items []AgingItem, asOf time.Time) AgingReport`
